# Documentation (`docs/`)

## Contrat

- La documentation doit décrire l'état réel du projet.
- Toute commande documentée doit exister dans `package.json` ou être explicitement externe.
- Ne jamais documenter un contournement non supporté par les règles `AGENT.md`.

## Anti-contournement

- Ne jamais placer de secret, URL client privée, identifiant projet Vercel/Neon ou donnée réelle dans un document.
- Les exemples doivent utiliser des placeholders clairement fictifs.
