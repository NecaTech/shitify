# Assets publics (`public/`)

## Contrat

- Assets statiques servis publiquement.
- Optimiser le poids des images avant commit.
- Nommer les fichiers selon leur usage produit, pas selon une source temporaire.

## Sécurité

- Ne jamais placer de document client privé, export, backup, secret ou fichier `.env` dans `public/`.
- Les logos ou assets client doivent être validés pour un usage web public.
